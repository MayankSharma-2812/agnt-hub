# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Agent Hub, please do not open a public issue. We appreciate responsible disclosure.

Please report vulnerabilities privately by opening a [GitHub Security Advisory](https://github.com/MayankSharma-2812/agnt-hub/security/advisories/new) or contacting the maintainers directly.

You will receive an acknowledgment within 48 hours, followed by updates on the fix and release schedule.
